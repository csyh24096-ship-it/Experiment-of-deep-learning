# Experiment-of-deep-learning（ディープラーニングの実験）
PythonとPyTorchなどのディープラーニングライブラリを用いた画像認識モデルの構築、最適化アプローチによる性能向上の実験記録です。

実験は基礎部分（C1,C2）から応用・最適化部分（C3,C4,C5）までの、C1～C5の5項目で構成されています。

開発環境には、Google Colabolatoryを利用しました。

## 実験概要と考察

実験のメイン部分である、モデルの構築および改良を行ったC3,C4,C5について概要としてまとめます。

### C3.1.ライブラリを用いたモデルの構築と学習\
MNISTデータを学習用データ、テスト用データとして利用し、PyTorchライブラリを用いてモデルの構築と学習を行いました。\

### C3.2.CNNモデルであるResNet50を用いた画像の分類\
PyTorchライブラリのtorchvision.modelsからResNet50のモデルの生成を行い、複数の画像の分類に対する結果を調べました。

### C4.MNISTモデルの最適化
MNISTデータを学習用データ、テスト用データとして利用し、モデルの構築と最適化を行いました。

### C5.手の画像認識
学習用データを自身で用意し、テストデータに対するモデルの構築と最適化を行いました。
TensorFlow Datasetsからrock_paper_scissorsをテスト用データとして利用しました。
