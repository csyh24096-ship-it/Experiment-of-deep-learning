# Experiment-of-deep-learning（ディープラーニングの実験）
PythonとPyTorchなどのディープラーニングライブラリを用いた画像認識モデルの構築、最適化アプローチによる性能向上の実験記録です。

大学の授業の中で行った実験であり、3名の共同実験者と共に実験を行いました。

実験は基礎部分（C1,C2）から応用・最適化部分（C3,C4,C5）までの、C1～C5の5項目で構成されています。

開発環境には、Google Colabolatoryを利用しました。

## 実験概要と考察

実験のメイン部分である、モデルの構築および改良を行ったC3,C4,C5について概要としてまとめます。

### C3.1.PyTorchライブラリを用いたモデルの構築と学習
MNISTデータを学習用データ、テストデータとして用いて、画像認識モデルを実装しました。
- **考察:** ライブラリの利用手順やその利点、学習ループの仕組みについて理解しました。また、ResNetなど実用的なモデルから、タスクに対する適切な層の構成とその目的について考え、モデルを構築する土台としました。

### C3.2.CNNモデルであるResNet50を用いた画像の分類
PyTorchライブラリのtorchvision.modelsからResNet50を読み込み、複数の画像の分類に対する推論結果を検証しました。
- **考察:** 既存のモデルを利用することのメリットを確認しました。その一方、事前学習したデータセットと離れた画像の入力した際の問題点を確認し、適切な利用、転用方法について理解しました。

### C4.MNISTモデルの最適化
MNISTデータを学習用データ、テスト用データとして利用し、推論精度の向上を目指してモデルの構築と最適化を行いました。その結果、精度が73.34%から93.76%に向上しました。

### C5.手の画像認識
学習用データを自身で用意し、TensorFlow Datasetsからrock_paper_scissorsをテストデータとする、より実践的なモデルの構築と最適化を行いました。その結果、精度が33.33%から57.53%に向上しました。

### 実験全体を通した考察
実験全体を通して得た学びを以下に示します。

1. 推論精度の向上：画像認識モデルの推論精度の向上にはモデルの層を深くするだけでなく、目的に応じた最適化手法の選択や過学習の抑制が有効であることが確認できました。そして何より質の高い十分な量のデータが不可欠であり、そのための適切な前処理、データの用意が重要であると実感しました。
2. モデル構築と過学習のコントロール：安易に層を深くするのではなく、学習データの数や複雑さなどに応じたモデル設計が不可欠だと感じました。学習データ数が少ない状況下ではドロップアウト層やバッチ正規化層を用いて汎化性能を担保するアプローチが有効でした。また、過学習や勾配消失問題を考慮し、層の深さや構成を考える必要があることを理解しました。
3. ハイパーパラメータのチューニング：層構成や学習データ数により適切な学習数や学習率が大きく変動します。理論だけでなく、実際の実行結果を元に調整を繰り返す過程の重要性を実感できました。
